Custo de importação

Cada encomenda pode ter vários produtos, cada um com seu próprio custo em dólar. A cotação usada é calculada a partir do que você realmente pagou (não uma cotação "de tabela") — e a taxa alfandegária, quando informada, é dividida entre os produtos proporcionalmente ao valor em dólar de cada um.

Aparência

Envie um arquivo do seu computador, ou cole o link de uma imagem já hospedada, para substituir o ícone de diamante padrão pela logo real da Point Supply, no site inteiro.

Pré-visualização:

Imagem de compartilhamento (WhatsApp, Instagram, etc)

A foto que aparece quando alguém compartilha o link do site. Use uma imagem com fundo sólido (não transparente), porque apps como WhatsApp mostram a prévia num cartão branco, e uma logo com fundo transparente pode "sumir". Importante: enviar o arquivo aqui guarda ele, mas não atualiza sozinho o que o WhatsApp/Facebook mostram — esses aplicativos não conseguem "ver" essa mudança automática. Depois de enviar, copie o link abaixo e peça pra colar ele fixo no código do site.

Pré-visualização:

Banners das categorias
